# Real Options
The tests a decision's set of options passes, so the user sees only real choices, each with what it costs. Apply them in this order:
- **The usual approach:** the set starts from how this is usually done, and says when an option departs from it, because the user can't weigh a departure they don't know is one.
- **A premise no one chose:** if every option shares a premise that bears on the question and that no decision picked, such as a library's default, its alternative is an option too, because the user can't turn down a default no one has shown them.
- **Only real choices:** an option stays only if it beats every other on something the user might care about, because one that's matched or beaten on every count isn't a choice. If only one holds up, the set is that one, with why the others fall away.
- **Full costs:** each option carries its whole cost, including costs it shares with the others, so none reads as cheaper than it is.
