# A Place a Pattern's Convention Doesn't Settle
If you can't tell whether a place breaks a pattern's Convention, work out what the Convention is for, and whether that settles it. If it doesn't, ask the user about that place, rather than guessing or stretching the wording to fit.

Their answer settles that place only, because a convention grown one edge case at a time gets applied by rote. It changes the Convention only if they say later code should follow it too.
