# Offering the Next Session
A skill that finishes a step in a worktree hands the user the next command from the note's `^status` line, to run in a new session. How you hand it on depends on whether this session opened the branch's PR and, if it didn't, on where that command runs:
- **If this session opened the branch's PR:** this worktree's work is done, and the worktree sweep at the next session start removes it once the PR merges. Give the user the command to run in a new session outside this worktree.
- **If the next command builds or reviews this branch,** such as `/implement`, `/infra-build` or `/final-review`: it runs in this worktree. Put up a New session card for it with `start_session`, with `initiation` "own_initiative", `context` "fresh", `use_worktree` false, the command with the note's name, such as `/infra-build <note name>`, as its `prompt` and a sentence on the story as its `background`. `use_worktree` false opens the session in this worktree's folder. The card takes the place of the command in your message.
- **Otherwise,** such as `/close` or a planning skill: it runs in the main checkout. Give the user the command to run in a new session there.
