# Splitting an Idea
Each story gets a placeholder now, and its real shaping later in its own session, so the context from this one doesn't carry over:
1. **One idea note per story.** Create it in `notes/features/<area>/` from `notes/templates/Idea.md`, with `type` left blank. Its Where It Stands line is just the next step: "Next: /shape ^status". Under Notes goes a line saying which idea it was split from (the original's name in plain text, not a link, since the next item deletes it), its one-line scope, and the parts of the user's idea that belong to it, in their wording. With them goes each decision from step 3 of `SKILL.md` that bears on the story: a settled one with its **Decided** and **Rejected** lines, and an open one as its question. If a part could belong to more than one story, or fits none, ask the user where it goes rather than dropping it. Otherwise, write the notes without showing them first, and list in your summary which of the user's parts went into each.
2. **The original.** If it's an idea note, delete it as "Deleting a split or folded idea note" in `SKILL.md` describes. If it's a Roadmap line with no note, the next item replaces it.
3. **The Roadmap.** Each new note gets a line that links to it and embeds its status, as AGENTS.md describes under "Editing notes", placed as AGENTS.md describes under "Roadmap order".
4. **Stop.** Don't start shaping any of the stories in this session. List each new note with the command to run in a new session, e.g. `/shape <note name>`.
