# The `docs/` Coverage Audit
Send the `docs-coverage-auditor` subagent the scope.

File each finding as a fix story, as step 3 of the skill describes, not as AGENTS.md's "Doc gaps" rule says. The release freeze builds only what the goal note's `# Release` section links. For the same reason, an item in the Docs Updates note doesn't count as covering a finding. Each fix story's Notes say which doc the finding belongs in.
