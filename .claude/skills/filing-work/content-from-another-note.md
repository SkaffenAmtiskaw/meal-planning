# Content From Another Note
If the work relies on content from another note, such as part of its design, how that content comes along depends on the case:
- **If the work builds part of a hub's design:** embed the hub sections it builds rather than copying them, so the design stays in one copy, and make the note the work goes to one of the hub's children:
  - **Its `# Design Handoff`:** if it has no line for that hub yet, add one saying the sections below it come from that hub and are part of the note's design, such as "The sections below from [[Hub]] are part of this note's design." It goes after the note's own design, if it has one. Under that line, add an embed for each section the work builds, like `![[Hub#Section]]`. If a heading isn't unique in the hub, give the section a block ID and embed that.
  - **Its Purpose:** embed `![[Hub#Purpose]]`, so the hub's Meta-Instructions reach whoever works on the note.
  - **The hub:** add the note to its Child Stories. If the hub is in `notes/archive/`, also add the note to its `kept-for`.
- **If the note joins a hub with no design sections for it to build yet:** add only the Purpose embed and the Child Stories row above. `/place-design` adds the design embeds when it places the design.
- **If the work only relies on a hub's design,** without building any of it: embed the hub sections the work needs next to the work, rather than copying them, so the design stays in one copy. If the hub is in `notes/archive/`, also add the note to its `kept-for`.
- **If the work is moving out of that note,** such as a step of a story that's otherwise done: move it in full, with its image embeds and the handoff text it relies on, and leave a `🚛 Moved to [[<new home>]]` pointer behind. Once the old note is archived nobody reads it, so a summary would leave whoever builds the work guessing.
