# Spinning Off a Story
The change becomes a blank-type idea note from `.claude/note-templates/Idea.md`, and `/shape` picks its type. The steps, in order:

1. **Write the note.** How depends on where the change came from:
   - **A workflow note without a What Belongs Here section:** rewrite it in place, so links to it keep working.
   - **An item in a collecting note, or a description:** create it in the `features/` folder it fits, in the notes repo.

   Under Notes, put the change in the user's wording, and move their own lines, such as `[Sarah]` lines, there too. Add a line saying which case made it a story and why. Then remove the item from the collecting note, if it came from one.
2. **Give a new note a Roadmap line.** A rewritten workflow note keeps its line.
3. **Stop.** Tell the user to run `/shape <note name>` in a new session.
