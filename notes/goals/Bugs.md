# Purpose
Collects bugs in the shipped app: defects in behavior that already shipped, which no feature goal is working on, so no goal would take them on its own.

## What Belongs Here
- Bugs in the shipped app, security issues included.
- An urgent bug, such as a security issue or one a user reported, doesn't wait for a goal drawn from Bugs: Sarah marks its line 🚨 and it moves into Next.

Looks close but doesn't belong:
- Bugs in unfinished features. A bug in work a ranked goal is still building belongs to that goal.
- Dev tooling and CI bugs. They belong to [[Dev Tooling]].
- Tech debt that causes no symptom. Code that works but needs changing stays in [[App Health]].

# Out of Scope
- [[Calendar and Recipes Data Refresh]]: it stays with [[Calendar Page]] (2026-10-02).
