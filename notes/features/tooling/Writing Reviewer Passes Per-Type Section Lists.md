The writing standard has no rule against defining something by listing each note type's sections, such as a line that names a feature's Suggested Approach, a bug's Fix and a cleanup's Current State, so `writing-reviewer` doesn't catch it. In Cleanup Final-Review Review (2026-11-02), `writing-reviewer` passed such a line under "Show a Few Good Examples", saying "three short inline examples aren't a list of edge cases". The nearest rules are in `.claude/skills/writing-standard/instructions.md` ("Show a Few Good Examples" and "Match Freedom to How Fragile the Task Is"), checked by `.claude/agents/writing-reviewer.md`. The same kind of line has now been written and then reworded in several reviews (Bug Final-Review Review, Pattern Final-Review Review, Cleanup Final-Review Review).
